📖 Sobre o projeto

O SG Pet Care é um site institucional desenvolvido com o objetivo de apresentar uma empresa do segmento pet, destacando seus serviços, sua identidade visual e o relacionamento com seus clientes.

O projeto foi desenvolvido com foco em uma navegação intuitiva, organização das informações e adaptação a diferentes dispositivos.

✨ Funcionalidades

🏠 Apresentação institucional da empresa.

🐶 Exibição dos serviços oferecidos.

🖼️ Carrossel de fotos dos clientes com navegação manual e automática.

📍 Seção de localização.

📱 Layout responsivo para diferentes tamanhos de tela.

🎨 Identidade visual personalizada.

🚀 Como executar o projeto

Clone o repositório:

git clone https://github.com/joaovitor-ds/SG-Pet-Care.git

Entre na pasta do projeto:

cd SG-Pet-Care

Abra o arquivo index.html no navegador.

Não é necessário instalar dependências para executar o projeto.
